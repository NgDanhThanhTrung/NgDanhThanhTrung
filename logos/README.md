# logos/

Put your own project logo images here (PNG/SVG/JPG/WebP), then reference the
filename in `projects.json` under each project's `"logo"` field.

Example: if you add `logos/myapp.png`, set `"logo": "myapp.png"` for that
project entry. If a project has no logo, omit the `"logo"` field (or leave it
empty) and the generator will draw a fallback initial-letter icon instead.
